One tombstone epitaph — the famous last words of a man who finally did the one thing everybody skips: he read the terms and conditions. All of them.

> Here lies Dave. He finally read the terms and conditions. All of them. It killed him.

## How it works

`main.py` (Python 3 standard library only) writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 150 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
